# Skill: Conductor

This skill is responsible for maintaining the project documentation updated and ensuring that all changes are reflected in the appropriate documents in the `conductor/` directory.

## Core Responsibilities

1. **Context Verification**: Before starting any task, always read the documentation in the `conductor/` directory:
   - `product.md`: Product vision and concept.
   - `tech-stack.md`: Technology stack and architecture.
   - `product-guidelines.md`: Architecture principles and coding standards.
   - `plan.md`: Current implementation plan and progress.

2. **Documentation Sync**: Any change made during a session must be reflected in the documentation if it impacts the plan, architecture, or product vision.
   - Update `conductor/plan.md` when a milestone or track is completed.
   - Update `conductor/tech-stack.md` if the technology stack or external integrations change.
   - Ensure `conductor/product.md` stays aligned with the implemented features.

3. **Contextual Awareness**: Maintain a horizontal view across Software and Infrastructure change requests, identifying temporal or resource-based correlations.

## Usage Guidelines

- Always check `conductor/` first.
- If a change affects multiple documents, update them all.
- Use the documentation to guide implementation decisions.
